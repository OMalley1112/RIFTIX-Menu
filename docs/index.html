// install

Up in three steps

01

Install BepInEx 5

Grab BepInEx 5 (x64) for Gorilla Tag and let it run once.

02

Download RIFTIX

Get RIFTIX.dll from the latest release.

03

Drop it in

Extract into Gorilla Tag/BepInEx/plugins/RIFTIX/ and launch the game.

Building from source? Clone the repo, set <GamePath> in Directory.Build.props, then run dotnet build — the DLL copies into your plugins folder automatically. Building from a terminal avoids the Visual Studio Smart App Control error (0x800711C7).
